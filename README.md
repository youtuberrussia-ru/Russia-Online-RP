# RUSSIA ONLINE RP

An original mobile open-world role-play game project. This repository starts with the secure server foundation, product architecture, and implementation roadmap.

## Project principles

- Original world, branding, code, and assets; no copying of protected competitor content.
- Server-authoritative gameplay and economy.
- Fair progression without pay-to-win purchases.
- Android-first performance, with architecture that can support additional clients later.
- Privileged actions are permission-checked on the server and fully audited.

## Status

Initial repository setup. The first implementation milestone establishes the backend domain model, authentication boundaries, organization/rank data, admin permission model, economy transaction rules, anti-cheat event handling, and automated checks.

See `docs/ROADMAP.md` and `docs/ARCHITECTURE.md` for the implementation plan.
