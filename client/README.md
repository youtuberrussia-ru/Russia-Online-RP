# Android 3D client

The planned game client is Unity 3D with an Android-first rendering and input profile. It is deliberately not represented as a fake playable prototype in this backend milestone. The client milestone will establish the Unity project, original city blockout, touch controls, character controller, camera and API session integration.

All consequential game state must be validated by the server. Never put database credentials, privileged API keys, admin authority or anti-cheat decisions in the client.
