# Store preview

Static catalogue for the RUSSIA ONLINE RP mini-store. It is deployed with GitHub Pages.

Important:
- This is a preview catalogue, not a checkout.
- No payments, card details, personal payment data or purchase claims are collected here.
- Do not add secret keys to this folder.
- Before enabling real payments, an eligible adult account holder must arrange provider approval, terms, privacy notices, refund/chargeback procedures and applicable tax requirements.
- Paid items must be cosmetic or convenience-focused and must not sell admin powers, rule immunity or unfair combat advantages.
- Backend must verify provider-signed webhooks and grant entitlements idempotently. Never grant items based on a browser redirect or screenshot.
